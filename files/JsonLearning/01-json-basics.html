Lesson 01 | Data before the interface

JSON Basics

JSON is a text format for moving structured data between systems. In this lesson, you will inspect real JSON, access nested values, transform arrays, and prepare data for a browser application.

Curriculum home Open JSON data Open annotated JavaScript Next: Browser JavaScript

What you should be able to do

Read the shape

Identify strings, numbers, booleans, null values, arrays, objects, and arrays of objects.

Use the data

Access nested properties, loop through records, filter results, and handle missing values safely.

Move between formats

Convert JavaScript data to JSON text with JSON.stringify() and parse JSON text with JSON.parse().

Prepare for the browser

Load JSON with fetch() and identify the loading, success, empty, and error states an interface needs.

1. Read the shape

Open learn-json.json beside this page. The top level is an object with four properties: student, company, products, and settings.

const studentName = data.student.name;
const firstProduct = data.products[0].name;
const companyEmployees = data.company.employees;
Important: JSON keys and string values use double quotes. JSON does not allow comments, functions, undefined, or trailing commas.

2. Work with nested data

The company contains an array of employee objects. Each employee has another object called contact and an array called skills.

data.company.employees[0].contact.email
// "maria@example.com"

data.company.employees[1].skills[0]
// "Java"

data.company.employees.filter(employee => employee.active)
// Maria and James

Use optional chaining and nullish coalescing when a value may not exist:

const phone = data.company.employees[1].contact.phone ?? 'No phone on file';

3. Transform the collections

Map

Create a new array from every item.

const names = data.company.employees
  .map(employee => `${employee.firstName} ${employee.lastName}`);

Filter

Keep only items that match a condition.

const inStock = data.products
  .filter(product => product.inStock);

Find

Get the first matching item.

const hub = data.products
  .find(product => product.sku === 'C300');

Reduce

Combine items into one result.

const inventoryValue = data.products
  .reduce((total, product) => total + product.price, 0);

4. Convert JSON and JavaScript data

The `.json` file is text. Once JavaScript parses it, you work with an object. The reverse conversion is useful when saving or sending data.

const jsonText = JSON.stringify(data);
const formattedText = JSON.stringify(data, null, 2);
const parsedData = JSON.parse(jsonText);

Open learn-json-annotated.js to compare valid JSON with the commented JavaScript version. The annotated file is easier to study, but it is not a valid JSON file because it contains comments and module.exports.

5. Load JSON in a browser

When you use fetch(), the file can fail to load. Practice handling every state instead of assuming the request succeeds.

async function loadData() {
  try {
    const response = await fetch('learn-json.json');
    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    const data = await response.json();
    console.log(data.products);
  } catch (error) {
    console.error('Could not load the data:', error);
  }
}

loadData();
When opening an HTML file directly, browsers may restrict fetch() because of local-file security rules. Use a local server for this exercise.
