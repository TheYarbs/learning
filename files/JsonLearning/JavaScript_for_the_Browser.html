Part 1 The Browser and the DOM

What Is the DOM?

When a browser loads a page it creates a Document Object Model (DOM) — a tree of objects representing the page. JavaScript reads and manipulates this tree in real time. Everything we scraped came from the DOM, not from Amazon's servers directly.

💡 The Kindle project scraped content already loaded in the browser — no API keys, no server access required.
📖
MDN: DOM Scripting developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/DOM_scripting Start here — DOM trees, querySelector, textContent, element traversal

CSS Selectors

Selectors are patterns used to find elements. The two key methods:

querySelector()    // returns the FIRST matching element
querySelectorAll() // returns ALL matching elements

Examples from the Kindle project:

[data-testid="book-list-view"]       // book cards
[data-testid="collection-list-view"] // series/collection cards
[data-testid="cover-img-title"]      // book title text

Counting Elements

Always measure before automating. Measurement is the foundation of debugging.

document.querySelectorAll('[data-testid="book-list-view"]').length

Browser Developer Tools

Open with F12 (Windows) or Cmd+Option+I (Mac). The Console tab is your primary workspace.

  • Elements — inspect the HTML structure
  • Console — run JavaScript live against the page
  • Network — see API calls happening in the background
  • Right-click any element → Inspect — jump to it in the DOM

Part 2 JavaScript Fundamentals

NodeLists vs Arrays

querySelectorAll() returns a NodeList — not a true array. Convert it with the spread operator to unlock map(), filter(), and reduce():

[...document.querySelectorAll(...)]
📚
javascript.info javascript.info Best free JS textbook — keep open while coding. Focus on Arrays, Functions, Promises, Async/Await, DOM.

map(), filter(), reduce(), find(), some()

Most scraping scripts are just these methods chained together.

map() — Transform

Takes every item and converts it into something else.

[...document.querySelectorAll('[data-testid="cover-img-title"]')]
  .map(el => el.textContent.trim())

filter() — Remove unwanted items

Keeps only items that pass a test.

[...document.querySelectorAll('a')]
  .map(a => a.href)
  .filter(href => href.includes('/homedetails/'))

reduce() — Collapse to a single value

collections.reduce((sum, el) => {
  const m = el.textContent.match(/(\d+)\s+books?/i);
  return sum + (m ? parseInt(m[1], 10) : 0);
}, 0)

find() and some()

books.find(b => b.title === "Dune")     // first match
books.some(b => b.author === "Herbert")  // true/false

Extracting Text

element.textContent.trim()

textContent gets text from the element and its descendants, including hidden descendants. Use innerText when you specifically need rendered text. trim() removes whitespace at the edges.

Data Structures

Array — ordered list

const books = ["Dune", "Foundation", "Hyperion"];

Object — named properties

const book = { title: "Dune", author: "Herbert", year: 1965 };

Set — unique values only

const seen = new Set();
seen.add("Dune");
seen.add("Dune"); // ignored — already exists
console.log(seen.size); // 1

Map — key-value pairs

const books = new Map();
books.set("title|author", { title: "Dune", author: "Herbert" });
Part 3 Browser Automation

Simulating Clicks

document.querySelector('#collection-list-view-B087Q2GTVF')?.click();

The ?. is optional chaining — prevents errors if the element doesn't exist. If null, returns undefined instead of crashing.

Async/Await and Promises

After clicking a button that loads content, wait before reading it:

await new Promise(r => setTimeout(r, 2500)); // pause 2.5 seconds
async function run() {
  doSomething();
  await pause(2500);  // wait for page to update
  readResults();      // now safe
}

Lazy Loading

Amazon loads books only as you scroll. Trigger this automatically:

const timer = setInterval(() => {
  window.scrollTo(0, document.body.scrollHeight);
}, 2000);
clearInterval(timer); // stop when done
Part 4 Data Export

Deduplication

Books appear multiple times when opening collections. Use a composite key with Set:

const seen = new Set();
for (const b of books) {
  const key = `${b.title}|${b.author}`;
  if (!seen.has(key)) { seen.add(key); unique.push(b); }
}

Generating CSV

CSV is readable by Excel, Google Sheets, and most databases.

const csvField = value => `"${String(value ?? '').replaceAll('"', '""')}"`;
const csv = [
  'Title,Author,Series',
  ...books.map(b => [b.title, b.author, b.series].map(csvField).join(','))
].join('\n');

Downloading Files from the Browser

No server required — JavaScript can create and download files in memory:

const blob = new Blob([csv], { type: 'text/csv' });
const url = URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url; a.download = 'output.csv'; a.click();
URL.revokeObjectURL(url);
Part 5 URL Harvesting & Practice Exercises

Run these in the browser console on any webpage. The pattern: find → extract → filter → deduplicate → copy.

Ex 1 Count all links on a page 
document.querySelectorAll('a').length
Ex 2 Extract all URLs 
[...document.querySelectorAll('a')].map(a => a.href)
Ex 3 Extract all images 
[...document.querySelectorAll('img')].map(img => img.src)
Ex 4 Harvest filtered, deduplicated URLs (Zillow example) 
copy(
  [...new Set(
    [...document.querySelectorAll('a')]
      .map(a => a.href)
      .filter(href => href.includes('/homedetails/'))
  )].join('\n')
)

Replace /homedetails/ with any pattern. Works on Amazon, eBay, Reddit, forums, Zillow.

Ex 5 Export page headings to CSV 
const csvField = value => `"${String(value ?? '').replaceAll('"', '""')}"`;
const h = [...document.querySelectorAll('h1,h2,h3')]
  .map(el => [el.tagName, el.textContent.trim()].map(csvField).join(','));
copy(['Tag,Text', ...h].join('\n'));
Ex 6 Kindle diagnostic count 
console.log("Books:", document.querySelectorAll('[data-testid="book-list-view"]').length);
console.log("Collections:", document.querySelectorAll('[data-testid="collection-list-view"]').length);
Part 6 Debugging Methodology

The Workflow

1
Measure first — count what exists before touching it
2
Verify assumptions — check selectors actually match elements
3
Write small tests — one line at a time in the console
4
Automate gradually — only after manual steps work reliably
5
Validate results — confirm output matches expectations
In the Kindle project: counted books (115), counted collection books (33), confirmed 115 + 33 = 148 matched Amazon's total, then automated. Never wrote the full script until we knew exactly what we were dealing with.

Full Kindle Export Script

(async () => {
  const books = new Map();
  function collect() {
    document.querySelectorAll('[data-testid="book-list-view"]').forEach(el => {
      const title = el.querySelector('[data-testid="cover-img-title"]')?.textContent?.trim();
      const author = el.querySelector('[data-testid="cover-img-author"]')?.textContent?.trim();
      if (title) books.set(`${title}|${author}`, { title, author });
    });
  }
  collect();
  for (const col of document.querySelectorAll('[data-testid="collection-list-view"]')) {
    col.click(); await new Promise(r => setTimeout(r, 2500));
    collect(); history.back(); await new Promise(r => setTimeout(r, 2500));
  }
  const csvField = value => `"${String(value ?? '').replaceAll('"', '""')}"`;
  const csv = ['Title,Author', ...[...books.values()]
    .map(b => [b.title, b.author].map(csvField).join(','))
  ].join('\n');
  const a = document.createElement('a');
  a.href = URL.createObjectURL(new Blob([csv], { type: 'text/csv' }));
  a.download = 'kindle.csv'; a.click();
})();
