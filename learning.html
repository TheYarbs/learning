Recommended sequence

Learn in this order

HTML and CSS

Semantic structure, forms, responsive layout, focus states, and accessible labels.

JavaScript essentials

Variables, functions, conditions, loops, scope, events, and error handling.

Data and APIs

Arrays, objects, JSON, fetch, loading states, errors, and empty results.

DOM applications

Render data, respond to forms, update state, filter lists, and persist with localStorage.

Export and automation

Build reliable CSV/JSON export first, then learn scraping and condition-based automation.

Quality and delivery

Add tests, accessibility checks, Git habits, modules, and eventually Playwright.

Your next seven days

One focused week

Days 1-2: render

  1. Put movie records in a JavaScript array.
  2. Write a function that renders each movie.
  3. Replace the hard-coded list in Movie Watch Hub.

Days 3-4: interact

  1. Add watched and favorite controls.
  2. Add search and status filters.
  3. Handle an empty result clearly.

Days 5-7: persist

  1. Save the movie state to localStorage.
  2. Add reset and JSON export.
  3. Document one bug and its fix.

A study method that compounds

Repeat for every topic
1. Build a small working example.
2. Break it deliberately.
3. Fix it without looking at the answer.
Write down the expected output before you run the code. Then compare the actual result and explain the difference in plain language.

After the foundation

Once you can build and debug the Movie Watch Hub and Airport Finder, move on to regular expressions, data cleaning, modules, npm, testing, browser extensions, Playwright, Python persistence with SQLite, accessibility audits, performance, security, privacy, rate limits, and scraping ethics.

For reference material, use the existing Browser Scraping Academy after you have completed the application work.

Keep the projects small enough to finish and difficult enough to make you think.
